# ActionDoc AI

**공문과 안내문에서 필요한 내용과 다음 행동을 찾는 문서 도우미입니다.**

문서를 넣고 확인할 목적을 선택하면 주요 내용, 제출 자료, 금액, 기한과 주의 사항을 항목별로 정리합니다. 각 항목의 원문 근거도 함께 확인할 수 있습니다.

## 주요 기능

- **문서 입력** — PDF·HWP 5·HTML·TXT·MD 파일 또는 텍스트 붙여넣기
- **목적별 정리** — 전체 정리 / 공문·업무 요청 / 지원사업·모집 공고 / 요금·계약 안내
- **원문 근거 확인** — 발췌한 문단과 PDF 쪽 번호 표시
- **결과 저장** — 정리 결과를 마크다운 파일로 다운로드

## 웹과 Mac에서 사용

| 구분 | 웹 기본판 | Mac 앱 |
| --- | --- | --- |
| 무료 기본 정리 | 로그인 없이 브라우저에서 사용 | 설치 후 사용 |
| 문서 처리 | 브라우저 안에서 처리, 서버 업로드 없음 | 사용자 Mac에서 처리 |
| 스캔 PDF OCR | 한국어·영어 | 지원 |
| AI 문맥 요약 | 운영 설정 후 짧은 문서 무료 요약 | 개인 OpenAI API 키로 선택 사용 |
| 기록·후속 작업 | 결과 파일 다운로드 | 분석 기록 저장·작업 등록·원문 연락처 연결 |

**무료 기본 정리는 원문을 항목별로 발췌하는 기능입니다.** 문맥을 새로 작성하는 AI 요약이나 개인별 자격 판단은 제공하지 않습니다. Mac 앱의 AI 분석은 외부 전송 동의 후 실행되며, 본인 API 사용량에 따라 비용이 발생합니다.

## 이용 방법

1. 파일을 선택하거나 본문을 붙여넣습니다.
2. 확인할 목적을 선택하고 문서를 정리합니다.
3. 결과와 원문 근거를 확인한 뒤 필요한 내용을 저장합니다.

파일은 **최대 50MB**, PDF는 **최대 50쪽**, 추출 본문은 **160,000자**까지 지원합니다. HWP는 원본 쪽 번호와 표 배치를 보존하지 않으며, HWPX와 보호된 HWP 문서는 지원하지 않습니다. 금액·기한·표·예외는 원본 문서와 함께 확인해 주세요.
